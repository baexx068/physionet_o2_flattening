# o2pulse_flattening

Analysis code and summary results for:

> Bae J-H. O₂ pulse flattening at the end of maximal treadmill exercise (title to be confirmed). Manuscript in preparation (2026).

## Data

The analysis uses the open registry *Treadmill maximal exercise tests from the Exercise Physiology and Human Performance Lab of the University of Málaga* (version 1.0.1; Mongin et al. 2021), distributed by PhysioNet: <https://doi.org/10.13026/7ezk-j442>.

The raw records are **not** included here. Download `subject-info.csv` and `test_measure.csv` from PhysioNet under its data use agreement and place them in `raw/` at the repository root (or point the environment variable `O2P_RAW` to their folder). The notebooks check both files against recorded SHA-256 checksums and stop if they differ.

Participant-level derived files (test-level O₂ pulse slopes and classifications `per_test.csv`, regression influence statistics, outlier lists, machine-learning features and out-of-fold predictions, figure data) are also not included, because they are derived records of the registry. They are regenerated by the notebooks; `SHA256SUMS.txt` in each results folder lists their checksums so that a re-run can be compared with the author's run. Figures are regenerated in `figures/` by the same notebooks.

## Running

Python 3.12 with the packages in `requirements.txt`. Run the notebooks from their own folders with *Restart & Run All*, in this order:

```bash
pip install -r requirements.txt
# 1. main analysis -> results_o2p_v3/
jupyter nbconvert --to notebook --execute --inplace code_o2p_v3/o2p_flattening.ipynb
# 2. machine learning (about 1 h on the author's laptop CPU) -> results_o2p_ai_v2/ ; reads results_o2p_v3/per_test.csv
jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=-1 code_o2p_ai_v2/o2p_ai.ipynb
```

Environment variables (optional): `O2P_RAW` (raw folder), `O2P_OUT` (output folder; a notebook stops rather than overwrite an existing one), `O2P_PERTEST` (input of notebook 2). The notebooks write to `results_o2p_v3/` and `results_o2p_ai_v2/`; the folders with the suffix `_pi` hold the author's run used for the manuscript.

To check the manuscript numbers after a re-run: `python code_o2p_manuscript/verify_o2p.py results_o2p_v3 results_o2p_ai_v2 <manuscript folder>` (the manuscript text itself is not part of this repository until publication).

Each notebook first verifies its statistical engine (Wilson interval, Cohen κ, least-squares slope, logistic regression, AUC, Nadeau–Bengio interval, participant-disjoint splits; see `engine_check.csv`) and stops if a check fails. Code comments and printed messages are partly in Korean.

## Reproducibility

- Participants were split 30% screening / 70% sealed with a fixed seed (20261021); all primary estimates come from the sealed subset.
- The notebooks were run by the author (Windows 11, versions in `requirements.txt`) and independently in a Linux container with scikit-learn 1.8.0. The primary and secondary estimates were identical to at least ten decimal places and all 19 decisions agreed; machine-learning estimates differed by up to 0.096 because of library versions. Keras training uses `set_random_seed` with operation determinism, so a re-run is identical only on the same machine and versions.
- Outside the pre-specified plan: two tests were excluded post hoc for implausible gas signals (results before exclusion are reported); the protocol analyses SE8–SE10 are data-informed (motivated by the machine-learning results); two exclusion analyses are labelled post hoc in `posthoc.csv`.

## Notes

- Exercise end: first time after maximal speed at which speed fell more than 2 km·h⁻¹ below its maximum. Flattening: least-squares slope ≤ 0 of O₂ pulse (10-s bins of V̇O₂/HR) over the final 120 s.
- The code was written with the assistance of a large language model (Claude, Anthropic) and checked by the author, as stated in the manuscript.
